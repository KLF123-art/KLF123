# 🍳 AI 食光机

> 《人工智能基础与应用》课程大作业 —— 智能配菜与食谱推荐网页

输入你现有的食材、口味偏好和忌口，AI 食光机会像营养师一样为你打分推荐食谱，附上做法、营养分析，并能生成一周菜单和购物清单。纯前端静态网页，无需后端、无需联网，可直接部署到 GitHub Pages。

---

## 一、项目概述

- **项目名称**：AI 食光机
- **作品形式**：交互式网页（纯静态）
- **选题方向**：AI + 食品（呼应课程"鼓励 AI 交叉"的要求）
- **目标用户**：不知道"今天吃什么"的学生、上班族、健身人群、厨房新手
- **解决问题**：把冰箱里零散的食材，变成可执行、有营养依据的一餐，降低做菜决策成本

## 二、核心功能与模块结构

| 模块 | 功能 |
|---|---|
| ① 食材输入面板 | 6 类 46 种食材多选 + 搜索、口味/辣度/难度/餐次/份量设置、6 种忌口过滤 |
| ② AI 智能配菜引擎 | 四维加权打分（食材40% + 口味25% + 营养20% + 难度时长15%）+ 忌口硬性过滤 + 主食材去重 + 动态推荐理由 + "为什么推荐"可解释面板 |
| ③ 食谱卡片与详情 | 匹配度徽章、做法步骤、用料（区分已有/需购买）、AI 小贴士、营养数据 |
| ④ 营养分析面板 | 单菜营养卡 + 一周每日平均营养条形图 |
| ⑤ 收藏与导出 | localStorage 收藏、自动生成一周菜单、购物清单复制、菜单打印 |

## 三、主要操作流程

进入首页 → 勾选食材和偏好 → 点击"AI 帮我配菜"（思考动画）→ 浏览推荐（匹配度 + 理由）→ 查看做法与营养 → 收藏 → 生成一周菜单 → 复制购物清单 / 打印。

## 四、技术原理

**推荐算法**是项目的"AI 内核"，用一个可解释的加权打分函数模拟营养师的决策：

```
总分 = 食材匹配度(≤40) + 口味契合度(≤25) + 营养均衡度(≤20) + 难度时长(≤15) + 餐次加成
```

- 忌口/过敏原作为**硬性过滤**前置处理（ vegetarian / lowfat / noSpicy / noSeafood / noPeanut / noDairy ）。
- 完全没用到所选食材的食谱降权 0.55，避免无关推荐。
- 同一批结果按主食材去重，保证多样性。
- "换一批"通过随机种子注入 ±3 分扰动，产生不同排序。

技术栈：原生 HTML + CSS + JavaScript，无任何构建工具和第三方依赖。数据存于 `js/data.js`，收藏/周菜单存于浏览器 localStorage。

## 六、部署到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `ai-food-machine`。
2. 把本目录所有文件上传到仓库根目录（确保 `index.html` 在根目录）。
3. 进入仓库 **Settings → Pages**。
4. Build and deployment → Source 选择 **Deploy from a branch**，Branch 选 `main`，目录选 `/ (root)`，保存。
5. 等待几十秒，访问 `https://<用户名>.github.io/ai-food-machine/` 即可。

> 注意：必须完成第 3-5 步开启 Pages，仅上传代码不算完成部署（对应作业要求）。

## 七、本地预览

直接双击 `index.html` 即可打开（数据全部内置，无网络请求）。
如需用本地服务器：

```bash
cd ai-food-machine
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```
